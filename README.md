# Chang Su — Portfolio

Personal portfolio for industrial designer and design researcher Chang Su. The site presents research and professional work for doctoral applications and design opportunities.

## Preview

Open `index.html` directly, or start any local static web server in this folder.

## Structure

- `index.html` contains the introduction, project index, research direction, and biography.
- `project.html` is the reusable case-study template.
- `project-data.js` contains the editable content and image references for all projects.
- `assets/` contains the images used by the published site.

## Updating

Edit the local files, preview `index.html`, then commit and push the changes through GitHub Desktop. GitHub Pages republishes updates automatically.
